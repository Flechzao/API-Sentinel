API Sentinel · 代码关联与污点分析

流量 → 源码定位 → audit_codebase 取 sink → trace_taint_source 后向回溯 → source↔sink 关联 → 交实测

源码定位工具

  • • search_source_code：端点 → 路由 handler
  • • find_definition / find_callers：符号定义与调用处
  • • grep_repo：仓库文本检索
  • • audit_codebase：全局白盒，枚举全部 sink

trace_taint_source 回溯

  • • 从 sink 变量向后回溯（正则启发式）
  • • StepKind：ASSIGNMENT / PARAMETER / SOURCE_MATCH
  • • 终止：SOURCE_MATCH / DEAD_END / HOP_LIMIT
  • • 返回 chain + other_call_sites_not_traced

可信边界（重要）

  • • 启发式回溯 ≠ 真实数据流分析
  • • 每一跳都需 read_file 核实，防止误接
  • • 受 PathSandbox 约束，仅读索引仓库内文件
  • • 关联出的链最终交 verify_* 实测才算证据
