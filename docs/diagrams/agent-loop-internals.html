API Sentinel · Agent 主循环内部机制

启动装配 → ReAct 每轮四步（感知→思考→工具→观察） → 循环护栏 → 三类终止　·　AgentLoop.java

ReAct 四步回环

  • • 感知：压缩历史，最近工具结果保留 30k tokens
  • • 思考：LLM 扩展思考，首轮/反思 6000、常规 1500
  • • 工具：真实发请求取证，无回显走 OOB 带外
  • • 观察：结果回填，检测异常 / WAF 后进入下一轮

成本 & 收敛护栏

  • • MAX_ITERATIONS = 50（安全断路器）
  • • 每轮 MAX_TOKENS_PER_TURN = 16384
  • • 最近结果预算 30k tokens，滚动保留
  • • 反思注入：连续 3 轮无异常 / 3 次 WAF 拦截

终止 & 兜底

  • • submit_report 通过门禁 → 正常结束
  • • cancel() 协作中断 → 证据兜底成文
  • • 达 50 轮 / 异常 → buildFallbackResult
  • • 任一路径都产出结构化结论，不空手而归
