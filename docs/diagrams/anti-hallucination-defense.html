API Sentinel · 反幻觉防御机制

LLM 假设 → 真实取证 → verify_* 闭环 → submit_report 门禁 → VerdictValidator 复核 → 可信输出（未过则降级）

verify_* 各自的签名

  • • boolean_blind：1=1 / 1=2 响应差异
  • • timing_blind：SLEEP 注入耗时 ≥ 4.5s
  • • xss_reflection：canary + 尖括号未编码
  • • ssti：{{7*7}} = 49 且有对照
  • • path_traversal / xxe：/etc/passwd 签名 · 实体读文件

submit_report 四道门禁

  • • Gate 1：heuristic_scan 必调
  • • Gate 1b：配库须先 audit_codebase
  • • Gate 2：报 N 个须实测 min(max(generated,N),5)
  • • Gate 4：有发现却没真发请求即拒（fail-closed）

VerdictValidator 复核

  • • 索引绑定 citedExecutionIndex，防张冠李戴
  • • evidence / 响应片段须逐字命中真实响应
  • • payload Jaccard 阈值过滤，加固类黑名单降级
  • • 未过 → confirmed 降级 suspected，降级留痕
